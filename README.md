# Cámara Pro

App Android de cámara enfocada en fotos de la mejor calidad, con controles PRO fáciles de usar.

## Qué incluye
- **Calidad máxima**: JPEG al 100 % y la resolución más alta que permita el teléfono (4:3).
- **Modos**: AUTO · PAISAJE · PRO · MACRO.
- **PAISAJE**: exposición un poco más baja (-0.7) + HDR para que el cielo y el fondo iluminado no se quemen.
- **PRO**: luz (EV), ISO, obturador, balance de blancos y enfoque manual, con datos en vivo.
- **MACRO**: busca la lente con el enfoque más cercano, muestra la distancia mínima real y tiene enfoque manual.
- **Zoom**: botones gran angular / 1x / 2x / 4x + pellizco. Toca para enfocar.
- Cuadrícula + nivel de horizonte, temporizador 3/10 s, flash, HDR, cámara frontal.
- Botones de volumen = disparador.
- Las fotos se guardan en Galería › ProCam.

## Compilar
1. Sube este proyecto a un repositorio de GitHub (rama `main`).
2. En la pestaña **Actions** corre solo "Compilar APK" (o ejecútalo con *Run workflow*).
3. Descarga `CamaraPro.apk` desde **Releases** (versión *latest*) e instálalo.
